# BarClean

![BarClean 标志](Resources/BarClean-logo.png)

适用于 macOS 27 的原生菜单栏应用。左键点击收纳图标或菜单栏空白处展开；右键打开设置窗口，在“隐藏”和“常驻”之间拖动第三方应用图标。设置中可切换标准、箭头、尖括号、省略号图标，选择登录时启动，并开关鼠标离开菜单栏 5 秒后自动收起；重新进入菜单栏会取消倒计时。识别空白处点击需要辅助功能权限，收纳图标本身不需要；不会接管其他图标或应用菜单。当前只对可唯一识别的常驻第三方图标核验实际排序；退出应用会解除隐藏。

## 构建与使用

本机只需 Swift Command Line Tools，无需 Xcode、Homebrew 或第三方依赖。当前脚本只构建 Apple 芯片（arm64）版本。

```sh
zsh build.sh
ditto build/BarClean.app /Applications/BarClean.app
open /Applications/BarClean.app
```

安装或更新前请先退出正在运行的版本。需要从 `/Applications` 启动，否则 macOS 27 可能连本应用的图标也一并隐藏。排序需要辅助功能和布局文件访问权，不需要屏幕录制。公开版更换了 Bundle ID，旧版设置、布局文件授权和辅助功能授权不会自动迁移，需要重新配置。当前构建使用临时签名。

“登录时启动”默认关闭，只在你主动勾选时注册当前应用为登录项；如系统要求批准，可通过设置界面的按钮打开系统登录项设置。关闭开关会注销登录项；此功能不会在未登录用户时启动应用。

首次打开设置时，点击“授权布局文件…”，在文件选择面板中选中 `~/Library/Group Containers/com.apple.MenuBar/Library/Preferences/com.apple.MenuBar.plist`。应用只获得此文件的访问权；仅切换隐藏状态不需要辅助功能权限。排序时还需点击“辅助功能…”并在系统设置中授权本应用，返回后点击“重新读取”。拖动可见的第三方图标后点击“应用排序”并确认，应用会先检查当前实际顺序、备份布局，再写入排序并刷新菜单栏服务；如果实际顺序没有变化，会尝试恢复备份并显示失败。

## 范围与限制

- 设置界面从 macOS 的布局文件读取记录，同一应用的多条记录合并显示为一行；记录数不等于当前实际显示的图标数。“常驻”的“当前”视图只列出菜单栏服务辅助功能子项中位于屏幕顶部、未标记隐藏且能与记录对应的第三方应用；其余条目放在只读的“未核验”视图，不再冒充当前图标。无法读取实际菜单栏时“当前”为空，并显示具体失败阶段。暂不支持移动系统图标、隐藏区组内排序，以及同一应用多条记录的组内排序；多条记录的应用可整体切换隐藏状态，同一应用的多个图标会一起隐藏。
- 不申请屏幕录制权限，不采集截图。布局文件受系统保护，需要你通过系统文件选择面板单独授权；如果 macOS 拒绝写入或实际顺序未变化，应用会显示失败，不会仅凭文件回读显示“排序成功”。
- 隐藏基于 macOS 27 的私有 `MenuBarClientCore` 接口。系统升级可能使它失效，届时应用会显示不可用状态。
- 隐藏单位是应用，而非同一应用的单个图标；Apple 系统图标仍保持显示。隐藏期间通知中心可能无法从时钟打开，可先左键展开图标。
- 应用必须保持运行；可在设置中启用登录时启动。受限制的应用如果不位于 `/Applications`，图标可能无法正常放行。
